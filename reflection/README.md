# reflection/

Content about *how to think* when producing a spec — separate from `pipeline/`, which is *what to do in what order*.

- [reasoning-chain.md](reasoning-chain.md) — standard reasoning chain (context → hypotheses → validation → decision) used when producing specs for Feature/Big feature tasks.
- [when-to-pause.md](when-to-pause.md) — when to stop and ask the user instead of deciding alone.
