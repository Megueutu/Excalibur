# reflection/

How to *think* while producing a spec — separate from [`../pipeline/`](../pipeline/), which is *what to do in what order*.

- [`reasoning-chain.md`](reasoning-chain.md) — the standard chain (context → hypotheses → validation → decision) used when producing specs for Feature / Big feature tasks.
- [`when-to-pause.md`](when-to-pause.md) — when to stop and ask instead of deciding alone.

Both are copied into the SDD destination during onboarding, and are translated if the project chose a language other than English — unlike `pipeline/` and `rules/`, which stay canonical in every project. A project can override either file with its own version in the destination.
