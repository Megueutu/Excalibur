# Testing policy — not required

- Tests are **never required** by the pipeline on this project.
- Never write a test that wasn't asked for. Adding one "while I'm here" is out of scope, same as any other unrequested change.
- If a change is genuinely risky without a test, say so once in the final report and let the user decide — don't add it unilaterally.
- The final review checklist does not check for tests on this project.
