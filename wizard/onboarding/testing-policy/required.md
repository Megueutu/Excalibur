# Testing policy — required

- Tests are **required** for every task classified as Feature or Big feature.
- Fix tasks require a test only when the bug was reachable through existing covered behavior.
- The final review checklist fails if a Feature/Big feature landed without a test — this is an objective gate, not a judgment call.
- "The change is too small to test" is not an accepted reason on a Feature; reclassify the task as a Fix instead, and say so.
