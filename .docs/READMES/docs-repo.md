# docs/repo/

Rules and documentation about maintaining **this repository** — as opposed to [`../../rules/`](../../rules/), which is content shipped into projects that install Excalibur.

| File | What it is |
|---|---|
| [`purpose.md`](purpose.md) | What Excalibur is and what it explicitly is not |
| [`structure.md`](structure.md) | Folder layout and which layer new content belongs to |
| [`git.md`](git.md) | Commit conventions for this repository |
| [`adding-a-harness.md`](adding-a-harness.md) | How to build an adapter for a new harness |

Every top-level folder of this repository carries a `README.md` explaining its function. That's a documentation convention for this repo only — it is not enforced on projects that use the framework.
